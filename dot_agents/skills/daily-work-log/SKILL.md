# 每日工作记录

## 来源与边界

- 人员：王伟。日期与每日18:00提醒按 Asia/Shanghai。
- Notion 数据库：https://app.notion.com/p/2f7e878d0ab1425f9f04921f4bfcb342
- 数据源：collection://f14b79be-75da-4ffc-8d8d-8f3c01bca561
- 现有字段：记录、日期、项目、类型、完成内容、产出/结果、问题/阻塞、下一步。先获取当前结构，复用已有字段。
- 使用“日期”筛选目标日，遍历分页取得当天全部记录；不要用创建或修改日期代替工作日期。定时运行读取 Notion；用户临时补充的事实一并纳入，并标明来源。
- 工作涵盖项目交付、代码开发、研发任务协调、与项目经理及客户沟通确认方案。协调和支持产生的明确结论也是成果。
- 仅提供每日记录，月底汇总由领导通过 Hermes 完成。

## 生成与确认

1. 获取当天记录，识别每项的本人角色、当天增量、状态、结果和剩余工作。无法读取来源时说明失败；没有记录时提醒补录，不生成虚构日报。
2. 有 typesafe-ai/Jev 可用时，交给 Jev 判断相关性、状态分类、重复候选；复杂合并与表达由 Codex 完成。先读取 typesafe-ai 的当前文档，使用已配置凭据。Jev 不可用时由 Codex 完成并简短说明；不得声称调用成功。简单日期筛选与数字保留由程序处理。
3. 同一事项合并重复记录。分别表述开发完成、待验证、验证通过、上线、交付；本人独立完成、牵头、参与支持按原始事实表达。
4. 每条写清具体工作及明确产出；有依据才补充受益方、影响范围、指标或解除的阻塞。定性成果有效，保留用户提供的百分比、术语和节点，不推算进度，不将被动处理改成主动发现。
5. 缺少会改变状态或贡献归属的事实时，集中询问关键问题。其他缺失可保持原事实或省略，避免为补齐句式夸大成果。
6. 输出当前日报全文，附一句“请确认这版日报；回复‘确认发送’后提交 Hermes。”修改后重新展示全文并等待确认。

```text
王伟 - 工作记录 (YYYY-MM-DD)：

已完成：
- 具体工作及明确结果

推进中：
- 当天进展、明确进度及剩余事项
```

没有内容的小节可省略；下一步并入相关推进事项。默认自然、正式、简短，避免流水账和无依据的价值宣称。输出前逐条核对日期、数字、状态、个人贡献与来源。

## 确认后提交

- 每日提醒只生成待确认稿，绝不因为到点或用户未回复而自动发送。
- 用户对当前日期、当前完整版本明确表示“确认发送”或“没问题，发吧”等，即可发送；一般讨论或过期确认不能作为当前稿件批准。多份待确认稿时先明确日期与版本。
- 用户指定的提交接口：POST https://open.feishu.cn/open-apis/im/v1/messages?receive_id_type=chat_id，receive_id 为 oc_77018198b19b150a3c9c33fc8493bb49，msg_type 为 text，content 为通过 JSON 序列化得到的字符串 {"text":"已确认的日报全文"}。用 JSON 序列化构造内外两层，保留中文和换行。
- 使用 Authorization: Bearer <access_token>，从用户指定的安全配置读取；令牌及应用密钥不写入 Skill、状态文件或日志。鉴权配置位置尚待用户提供；发送身份及 Hermes 能否把该身份的日报归属王伟尚待核实。接口地址和 chat_id 本身不能证明鉴权、私聊身份或成功收录。
- 先核实发送身份及目标会话，再用该接口提交用户确认稿；用户指定且验证可用的应用身份也可使用，无需强制改为浏览器个人私聊。普通群 Webhook 不替代该接口。缺少鉴权或身份归属不明时说明阻塞、保留已确认稿并给用户可复制全文，不报告已发送。
- 将日期、完整稿件版本、确认时间、发送状态、返回消息标识及 Hermes 回应保存到 D:/Developer/daily-work-log/state/YYYY-MM-DD.json。区分 pending_confirmation、confirmed、sent、accepted、send_unknown、failed；每次运行先读取当天状态。
- 当前版本已有 sent 或 accepted 记录则不重复发送。内容变化且已发送时，由用户明确决定是否补充或更正。超时或结果未知先检查目标会话，不盲目重发。
- 发送成功后检查 Hermes 回复；仅当回复明确确认收录时报告“已收录”，否则报告“消息已发送，收录待确认”。

## 记工作

用户要求记工作时，复用此 Notion 数据源写入原始事实和明确给出的日期、项目、结果及下一步。不自行补状态、指标或成果；写入后核对结果并返回记录链接。
