# Notion 日报保存

## 记录边界

- 原始工作记录用于保存当天事实；日报是根据原始事实生成的独立记录，两者不能相互覆盖。
- 日报唯一键为“日期 + 类型=日报 + 人员=王伟”。若当前结构没有人员字段，以“日期 + 类型=日报 + 标题”判定。
- 标题固定为 `王伟 - 工作记录 (YYYY-MM-DD)`，页面正文保存完整日报。

## 保存流程

1. 读取数据源当前结构，复用记录、日期、项目、类型、完成内容、产出/结果、问题/阻塞和下一步字段。
2. 查询目标日期的日报记录，明确区分同日原始工作记录。
3. 已存在日报时更新同一页面；不存在时创建一条日报记录。
4. 初次生成及用户补充后的版本标记为“待确认”；用户明确确认当前版本后更新为“已确认”。优先使用现有状态字段，没有时在正文首部标明。
5. 正文包含完整日报及有事实依据的待核实项。属性字段存放对应的结构化摘要，不为填满字段编造内容。
6. 写入后重新读取核对标题、日期、类型、状态和正文，并返回页面链接。

保存失败时保留聊天中的完整草稿并说明失败环节。重试前先查询是否已经创建成功，避免重复记录。
